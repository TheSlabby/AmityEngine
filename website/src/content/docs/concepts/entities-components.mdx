AmityEngine uses an **actor-component** model, like Unity's `GameObject`/`Component` or Unreal's `Actor`/`ActorComponent`.

<Aside type="note" title="Not an ECS">
The classes are named `Entity` and `Component`, but this is not a data-oriented Entity Component System. An `Entity` is an object that owns polymorphic `Component` instances. Nothing is stored in contiguous arrays.
</Aside>

## Entity

An `Entity` has a transform (position, rotation, scale), a name, and at most one component of each type.

```cpp
auto e = std::make_shared<Core::Entity>();
e->setName("Crate");
e->setPosition({0.0f, 1.0f, 0.0f});
e->setScale(glm::vec3(2.0f));
e->rotate(glm::radians(45.0f), {0.0f, 1.0f, 0.0f});
e->lookAt({10.0f, 0.0f, 0.0f});
```

### Component API

| Method | Description |
|---|---|
| `addComponent<T>(args...)` | Constructs `T`, sets its owner, calls `init()`, and returns it. Replaces any existing `T`. |
| `getComponent<T>()` | Returns the `T` component, or `nullptr`. |
| `hasComponent<T>()` | `true` if the entity has a `T`. |
| `removeComponent<T>()` | Detaches and removes the `T` component. Returns `false` if there was none. |

## Writing a component

Subclass `Core::Component` and override `init()` and/or `update(double dt)`. Use `getOwner()` to reach the entity.

```cpp title="SpinComponent.hpp"
#pragma once
#include <Component.hpp>
#include <Entity.hpp>

class SpinComponent : public Core::Component
{
public:
    explicit SpinComponent(float speed) : m_speed(speed) {}

    void update(double dt) override
    {
        getOwner()->rotate(m_speed * static_cast<float>(dt), {0.0f, 1.0f, 0.0f});
    }

private:
    float m_speed;
};
```

```cpp
entity->addComponent<SpinComponent>(1.5f);
```

## Built-in components

| Component | Purpose |
|---|---|
| `MeshComponent` | Renders a model with a shader at the entity's transform. |
| `CameraComponent` | Turns the entity into a camera (FOV, view and projection). |
| `PanTiltComponent` | Azimuth/elevation camera pointing. |
| `RigidBodyComponent` | Simple physics body. |
| `SoundComponent` | Positional OpenAL audio that follows the entity. |
